free foreverwhat "free" actually means here

No asterisks.

✓No subscription, no seats. Install it on every machine you own.
✓No usage limits. Hydra never meters requests. Providers do their own billing.
✓No telemetry. Routing, cost logs, and calibration stay on your machine.
✓No lock-in. Provider-neutral by design: swap models, go fully local, leave any time.
✓Open to inspect. The source is public, so you can see exactly how every routing and policy decision is made.
✓A $0 path always exists. With Ollama the terminal fallback is a free local model.
